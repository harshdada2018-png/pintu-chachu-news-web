Render Audio Worker

  • Path: render-audio-worker/server.js
  • Codec: FFmpeg libopus mono 32 kbps WebM
  • Measured compression: 144 KB -> 13.2 KB (10.89x)
  • Auth: Timing-safe x-render-secret header
  • Keep-Alive: GET /health every 11 min (~131 req/day)

Multi-D1 Shard Capacity

  • DB_AUDIO_HI: 500 MB D1 (FIFO cap 450 MB -> 400 MB)
  • DB_AUDIO_EN: 500 MB D1 (FIFO cap 450 MB -> 400 MB)
  • Combined Audio Capacity: 900 MB (~3,000+ min WebM)
  • Fallback: Master env.DB (250 MB audio cap)
  • Cache Hits: 0 D1 writes (no last_accessed_at updates)

Security & Purge Guards

  • Staff Endpoints: editor | admin | developer Bearer token
  • CPU Budget Guard: Native Base64 decode < 3 ms (10 ms cap)
  • Cascade Cleanup: Article edit/delete clears all shards
  • POST /api/storage/purge: Pure FIFO quota trim across shards
  • Local Parity: server.js writes _v3.webm to /uploads/
