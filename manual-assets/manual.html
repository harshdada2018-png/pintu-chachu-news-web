CHAPTER 2

Master Passphrase Security Architecture

PublicSpark Newsroom me standard password aur Google 2FA ke upar ek Sovereign Master Passphrase banaya gaya hai. Iska purpose hai: jab sabhi passwords, phones, ya tokens fail ho jayein, tab bhi system owner bina kisi GUI access ke system ko reclaim kar sake.

2.1 Passphrase Ka Nirman Aur Hardening

Aapne jo 14-character high-entropy master passphrase choose karke offline safe note kiya hai:

[YOUR_MASTER_PASSPHRASE]
Kyun Ye Passphrase Super-Hard Hai?
  • Length: 14 characters long.
  • Character Variety: Lowercase (m, f, q, v, x), Uppercase (K, W), Digits (9, 7, 4, 2, 8), Special Symbols (#, @).
  • Mathematical Entropy: 85+ bits entropy. Ek modern supercomputer ko ise brute-force se guess karne me lagbhag 2,400 saal lagenge.

2.2 Cryptographic Hash Storage (Zero-Plaintext Rule)

Security best practices ke mutabiq, ye plain passphrase codebase me plain-text format me store nahi kiya jata. Iska SHA-256 One-Way Hash derive kiya gaya hai:

MASTER_PASSPHRASE_HASH=652c396ac75da2038108462202dbf5c83977b55f0d4526356b64001ef343c57d

Ye hash .env file aur server/services/staffAuthService.js me safe rehta hai. Jab Aap terminal me passphrase enter karte hain:

  1. Node.js Aapke input ka SHA-256 hash banata hai.
  2. Dono hashes ko crypto.timingSafeEqual() se compare kiya jata hai.
  3. Timing-safe comparison se hackers CPU processing time measure karke passphrase guess nahi kar sakte.
CHAPTER 3

Emergency Disaster Recovery CLI (Local Terminal)

CLI tool ka path hai server/cli/emergency-lockdown.js, jise Aap direct npm run lockdown command se chala sakte hain.

Important Windows / PowerShell Rule

Chunki Aapke passphrase me # aur @ symbols hain, Windows PowerShell inhein command delimiter samajh sakta hai agar quotes na lagayein. Isliye terminal me hamesha double quotes lagakar chalayein: "".

3.1 Commands Ki Poori List

COMMAND 1 System & Account Status Check Karna 
npm run lockdown "" status

Kya karega: Poore system ka live audit print karega: Global lockdown active hai ya nahi, Super Admin ka 2FA ON hai ya OFF, aur sabhi 6 staff members ki summary.

COMMAND 2 Super Admin Ka 2FA Wipe Karna (Phone Gum Hone Par) 
npm run lockdown "" reset-2fa

Kya karega: Agar Aapka phone kharab ho gaya, Google Authenticator app delete ho gaya, ya codes reject ho rahe hain, to ye command Super Admin ke 2FA secret aur recovery codes ko purge kar dega. Agli baar Aap direct password se login karke naya phone QR scan kar sakenge.

COMMAND 3 Super Admin Password Restore Karna (Admin@2026) 
npm run lockdown "" reset-password

Kya karega: Super Admin ka password wapas default secure password Admin@2026 par reset kar dega aur account ko active status me le aayega.

COMMAND 4 Dunia Ke Sabhi Logins Ko 0ms Me Kill Karna 
npm run lockdown "" revoke-sessions

Kya karega: Server clock par revocation cutoff time stamp laga deta hai. Kisi bhi hacker, staff member, ya device par chal raha active session token instantly dead ho jayega.

COMMAND 5 Complete Emergency Lockdown (All Actions in One) 
npm run lockdown "" emergency-all

Kya karega: Full disaster recovery! Ek sath 3 kaam karega: Sabhi active sessions kill karega + password reset karega + 2FA wipe karega.

COMMAND 6 Interactive Number Menu Chalana 
npm run lockdown ""

Kya karega: Terminal par 1 se 7 tak ka interactive menu aayega. Aapko bas number (e.g., 1 ya 5) type karke Enter dabana hoga.

CHAPTER 4

Production Cloudflare D1 Serverless Operations

Aapne decide kiya hai ki pehle website ko Cloudflare Pages (Frontend) aur Cloudflare D1 (Database) par live karenge. Cloudflare serverless platform hai, isliye isme physical Linux black screen terminal nahi hota. Is par control ke 2 tareeqe hote hain:

4.1 Tareeqa A: Apne Laptop Ke Terminal Se (Wrangler CLI)

Aapko Cloudflare par login karne ki zaroorat nahi hoti. Terminal Aapke apne laptop me hi khulega aur Cloudflare ke live cloud database me changes karega:

STEP 1 Live D1 Database Par 2FA Reset Query Chalana 
npx wrangler d1 execute publicspark-db --remote --command="UPDATE newsroom_staff SET two_factor_enabled = 0, two_factor_secret = NULL WHERE email = 'admin@publicspark.in';"
STEP 2 Live D1 Database Par Sabhi Active Logins Kill Karna 
npx wrangler d1 execute publicspark-db --remote --command="UPDATE newsroom_staff SET tokens_invalidated_before = strftime('%s', 'now') * 1000;"

4.2 Tareeqa B: Mobile Phone Ya Chrome Browser Se (Web Console)

Agar Aapke paas laptop nahi hai aur Aap safar me hain, to apne mobile phone se Cloudflare console me jakar 1 minute me rescue kar sakte hain:

  1. Apne phone ke Chrome browser me kholiye: https://dash.cloudflare.com
  2. Left side menu me Storage & Databases par click karke D1 select kijiye.
  3. Apne database publicspark-db par tap kijiye.
  4. Upar "Console" tab par click kijiye (ye ek type box hota hai).
  5. Neeche diya gaya SQL paste karke "Execute" button daba dijiye:
-- CLOUDFLARE D1 EMERGENCY RESTORE SCRIPT
UPDATE newsroom_staff 
SET two_factor_enabled = 0, 
    two_factor_secret = NULL, 
    two_factor_recovery_codes = '[]',
    tokens_invalidated_before = strftime('%s', 'now') * 1000,
    status = 'active'
WHERE email = 'admin@publicspark.in';

Execute hote hi live website par 2FA deactivate ho jayega aur sabhi active hacker sessions kill ho jayenge.

CHAPTER 5

VPS Scale Migration & SSH Terminal Operations

Jab PublicSpark ka readership traffic lakhon me pahunch jayega aur Aap backend ko Cloudflare se dedicated VPS (Hostinger, Hetzner, AWS) par transfer karenge, tab Aapko traditional Linux terminal access milta hai.

5.1 VPS Par Terminal Access (SSH)

Apne Windows computer ke PowerShell se live VPS terminal me login karne ka command:

ssh root@your-vps-ip-address

Password dalte hi Aap live Linux server ke black screen terminal me pahunch jayenge.

5.2 Live VPS Par Emergency Lockdown Chalana

Live server par project folder me jakar wahi same command chalega jo local me chalta hai:

cd /var/www/publicspark
npm run lockdown "" emergency-all

Ye command chalte hi live VPS par server clock ke sath matching sessions kill ho jayenge aur super admin direct access me restore ho jayega.

5.3 Live VPS Server Process Management (PM2)

VPS par backend server ko 24/7 bina ruke chalane ke liye pm2 use kiya jata hai:

Task Terminal Command
Server ko 24/7 background me start karna pm2 start server/server.js --name "publicspark-api"
Server ka live status dekhna pm2 status
Live server ke logs / traffic dekhna pm2 logs publicspark-api
Server ko restart karna pm2 restart publicspark-api

4-Layer Cyber Incident Response Protocol

Agar kabhi suspicious activity dikhe ya lage ki kisi ne password guess kar liya hai, to ghabrane ki zaroorat nahi hai. System ko recapture karne ka step-by-step protocol ye hai:

LAYER 1 Attacker Ko Bahar Phekna (0 Seconds Me)

Terminal me ye command chalayein (ya Cloudflare Console se execute karein):

npm run lockdown "" emergency-all

Nateeja: Attacker ka session instantly expire ho gaya, wo site se bahar nikal gaya, aur uska 2FA device unbind ho gaya.

LAYER 2 Cloudflare Under Attack Mode Active Karna

Cloudflare Dashboard me jakar "Under Attack Mode" ka toggle ON kar dijiye. Isse koi bhi bot, automated script, ya DDoS flooding tool site ko touch nahi kar payega.

LAYER 3 Pura Clean Data 1-Click Me Restore Karna

Hamare Task 19 Auto-Backup Desk se download kiye gaye latest clean backup zip se database files (articles.json, settings.json) restore kar lijiye. Ek bhi article ya image lost nahi hogi.

LAYER 4 Fresh 2FA Pairing & Strong Password

Newsroom Staff Desk me login karke apna personal phone dobara fresh QR code se scan kijiye aur naya password set kar lijiye.
